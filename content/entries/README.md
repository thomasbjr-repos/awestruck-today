# Entries

One JSON file per approved entry, named `YYYY-MM-DD-short-name.json`. Only entries Thomas has set to Verified (or later) belong here; this folder is public.

Required fields: `date` (YYYY-MM-DD), `slug`, `title`, `person`, `theme`, `status`. The full entry layout (By the Numbers, See & Hear, Sources, Scripture credit lines) arrives with the Week 3 site build.
